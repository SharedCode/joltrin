Pilot worksheet

What would the pilot have stopped?

Run the barrier in observe mode on real agent traffic, then enter what it logged. The page multiplies your counts by your own cost estimates. It has no built-in numbers, and nothing you type leaves your browser.

Scope the pilot first

  1. Pick one runbook for one agent. A pilot that covers everything proves nothing.
  2. Write the success number down before you start, for example "fewer than N would-have-blocked steps a week by day 14".
  3. Set SOP_MODE=observe and SOP_DECISION_LOG=/path/decisions.log. Nothing is blocked; steps that would be are logged.
  4. After the pilot, run sop-mcp-server report /path/decisions.log and copy the counts below.
  5. Decide who signs off, and what result means enforce mode, a longer pilot, or stop.
